# Rehan Raza Shaikh — Portfolio

A React + Vite portfolio website for Rehan Raza Shaikh.

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Add certificate images

Place your real certificate images in:

`src/assets/certificates/`

The course data in `src/data.js` already contains the intended filenames. If you use different filenames, update the `image` field.

## Add project screenshots

Replace the SVG placeholders in:

`src/assets/projects/`

with your real screenshots if desired, or update the `image` fields in `src/data.js`.

## Resume

The portfolio intentionally does not contain a fake resume URL. Add your PDF later and connect the Resume button when ready.

- No Experience section is included.
- Raxar Technology and Solutions / CSRE IIT Bombay × VIT is not included.
